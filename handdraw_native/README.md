# Hand Draw Studio — Native Android (Kotlin + MediaPipe)

راهنمای فارسی

## این چیه؟
این یک اپ **بومی اندروید** با Kotlin است — نه یک برنامه‌ی پایتونی بسته‌بندی‌شده.
از **CameraX** برای گرفتن تصویر زنده‌ی دوربین جلو و از **MediaPipe Tasks Vision
(HandLandmarker)** برای ردیابی واقعی ۲۱ نقطه‌ی مفصلی دست استفاده می‌کند —
همان خانواده‌ی مدلی که در نسخه‌ی دسکتاپ پایتونی استفاده شده بود، این‌بار از
طریق API رسمی و پشتیبانی‌شده‌ی اندروید.

## معماری (نگاشت مستقیم از نسخه‌ی پایتون)
| نسخه‌ی پایتون (دسکتاپ) | نسخه‌ی Kotlin (اندروید) |
|---|---|
| `HandTracker` (opencv + mediapipe python) | `HandLandmarkerHelper.kt` (CameraX + MediaPipe Tasks) |
| `Drawing` (منطق نقاشی/undo/eraser/grab) | `DrawingView.kt` |
| `App` (pygame UI/toolbar) | `MainActivity.kt` + `activity_main.xml` |

ژست‌ها عیناً حفظ شده‌اند:
- **انگشت اشاره کشیده + بقیه‌ی انگشت‌ها جمع** → نقاشی
- **پینچ (نزدیک شدن شست و اشاره)** → گرفتن و جابه‌جا کردن یک خط
- پاک‌کن جزئی (partial eraser) دقیقاً با همان الگوریتم تقسیم قطعه‌ها

تفاوت طراحی نسبت به نسخه‌ی دسکتاپ: چون تصویر دوربین همیشه پشت بوم قابل مشاهده
است، نقاشی مثل یک لایه‌ی AR روی تصویر زنده‌ی دست شما ظاهر می‌شود. با دکمه‌ی
«▦ BG» می‌توانید بین پس‌زمینه‌ی دوربین و یک بوم سفید ساده جابه‌جا کنید.

## چطور APK واقعی بگیرید

### روش ۱ — GitHub Actions (توصیه‌شده، بدون نیاز به نصب چیزی)
1. محتوای این پوشه را در یک ریپازیتوری GitHub push کنید.
2. تب **Actions** → ورک‌فلوی «Build Android APK» به‌طور خودکار اجرا می‌شود
   (مدل MediaPipe به‌صورت خودکار در حین build دانلود می‌شود).
3. حدود ۱۰–۱۵ دقیقه طول می‌کشد. از بخش **Artifacts** فایل
   `handdrawstudio-apk` را دانلود کنید — یک APK نصب‌شدنی واقعی است.

### روش ۲ — روی سیستم خودتان (Android Studio)
1. پوشه را در Android Studio باز کنید (Open an existing project).
2. فایل مدل را دستی دانلود و در `app/src/main/assets/hand_landmarker.task`
   قرار دهید:
   `https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task`
3. Run ▶ روی گوشی یا شبیه‌ساز متصل.
